# Phase 3: Go Code Generator

## Goal

Implement `gen/codegen` — a package that takes a `*ir.SchemaIR` and produces a complete,
formatted Go source file (`config.gen.go`).

---

## Prerequisites

- Phase 1 complete: `internal/ir` types exist
- Phase 2 complete: parser exists (needed for integration test only; codegen itself only
  takes `*ir.SchemaIR` as input)
- Read `docs/design/developer-experience.md` — the canonical example of what
  `config.gen.go` should look like
- Read `docs/design/config-anatomy.md` — Sensitive, Computed, IsLive behaviour

## Public API

```go
package codegen

// Options configures code generation.
type Options struct {
    // Package is the Go package name for the generated file (e.g. "cmd").
    Package string

    // Module is the module import path prefix (e.g. "github.com/example/cfgx").
    // Used to build the import path for cfgx and cfgx/runtime.
    Module string
}

// Generate produces a formatted Go source file from schema.
// The returned bytes are ready to write to disk; they are gofmt-clean.
func Generate(schema *ir.SchemaIR, opts Options) ([]byte, error)
```

## Generated file contract

The generated `config.gen.go` must contain exactly these elements (in order):

### 1. File header

```go
// Code generated by cfgx. DO NOT EDIT.
// Source: cmd/schema.go

package <pkg>
```

### 2. Imports

Only the imports actually used. Always include:
- `"github.com/example/cfgx"`
- `"github.com/spf13/cobra"`
- `"github.com/spf13/viper"`

Conditionally include:
- `"github.com/example/cfgx/runtime"` — if any IsLive entries exist
- `"fmt"` — if Computed entries exist
- `"strings"` — if Sensitive entries exist (for the redacted String() method)

Use `"golang.org/x/tools/imports"` (goimports) if available, otherwise use
`go/format` and manage imports manually.

### 3. Root Config struct

```go
// Config holds configuration for all commands.
// It is populated by Load* functions.
type Config struct {
    AppName      string
    Debug        bool
    OutputFormat string
}
```

Only entries with no `.Scope()` (or empty scope) appear in the root struct.

### 4. Scoped structs

For each unique scope value (e.g. "serve", "migrate"), emit:

```go
// ServeConfig holds configuration for the "serve" command.
type ServeConfig struct {
    Config           // embed root
    Port        int
    TLSEnabled  bool
    Db          DbConfig
}
```

### 5. Object structs

For each `Object` entry, emit a `XxxConfig` struct:

```go
type DbConfig struct {
    host     string
    dbPort   int
    name     string
    user     string
    password sensitiveString  // see Sensitive type below
    dsn      func() string    // Computed
}
```

All fields are unexported. Expose via getter methods:

```go
func (c *DbConfig) Host() string     { return c.host }
func (c *DbConfig) DbPort() int      { return c.dbPort }
func (c *DbConfig) Name() string     { return c.name }
func (c *DbConfig) User() string     { return c.user }
func (c *DbConfig) Password() string { return string(c.password) }
func (c *DbConfig) DSN() string      { return c.dsn() }
```

### 6. Sensitive type

```go
// sensitiveString is a string that redacts itself in all string representations.
type sensitiveString string

func (s sensitiveString) String() string { return "[redacted]" }
func (s sensitiveString) GoString() string { return `sensitiveString("[redacted]")` }
func (s sensitiveString) MarshalJSON() ([]byte, error) { return []byte(`"[redacted]"`), nil }
func (s sensitiveString) MarshalText() ([]byte, error) { return []byte("[redacted]"), nil }
```

### 7. RegisterFlags

```go
// RegisterFlags registers all config entries as cobra flags on cmd.
// Call this on your root or per-command cobra.Command before Execute().
func RegisterFlags(cmd *cobra.Command, schema *cfgx.Schema) {
    flags := cmd.PersistentFlags()
    flags.Int("port", 8080, "HTTP port the server listens on")
    // ... one call per entry with FlagLong set
    // For Sensitive entries: usage text must NOT include the word "password" in the
    // default value; show empty string as default
    // For Deprecated entries: call flags.MarkDeprecated(name, message)
}
```

### 8. BindViper

```go
// BindViper binds all env var names and sets viper defaults.
// Call this after cobra.OnInitialize sets up viper.
func BindViper(v *viper.Viper, schema *cfgx.Schema) {
    v.BindEnv("port", "APP_PORT")
    v.SetDefault("port", 8080)
    // ... one pair per entry with Env set
}
```

### 9. Load functions

One `Load` function per scope (including a root `Load` for scope-less entries):

```go
// LoadServe reads configuration for the "serve" command from v.
// It validates all values and returns a typed *ServeConfig or a *ValidationErrors.
func LoadServe(schema *cfgx.Schema, v *viper.Viper) (*ServeConfig, error) {
    cfg := &ServeConfig{}
    cfg.AppName = v.GetString("app-name")
    cfg.Port = v.GetInt("port")
    cfg.Debug = v.GetBool("debug")
    cfg.Db.host = v.GetString("db.host")
    cfg.Db.password = sensitiveString(v.GetString("db.password"))
    cfg.Db.dsn = func() string { /* closure over cfg.Db fields */ }
    // ... populate all fields

    if err := schema.Validate(v); err != nil {
        return nil, err
    }

    // Set up IsLive watcher if any IsLive entries exist
    if schema.HasLiveEntries() {
        w := runtime.NewWatcher(5 * time.Second)
        // register entries...
        w.Start(context.Background())
    }

    return cfg, nil
}
```

## Name conversion rules

Implement in `gen/codegen/names.go`:

```go
// ToGoName converts a kebab-case or snake_case ID to PascalCase Go identifier.
// Handles common acronyms: ID, URL, TLS, HTTP, API, JSON, SQL, DB, SMTP.
//
//   "port"           → "Port"
//   "app-name"       → "AppName"
//   "tls-cert-path"  → "TLSCertPath"
//   "db"             → "Db"
//   "db-host"        → "DbHost"
//   "api-key"        → "APIKey"
func ToGoName(id string) string

// ToStructName returns a PascalCase struct name for an Object entry.
//   "db"   → "DbConfig"
//   "smtp" → "SmtpConfig"
func ToStructName(id string) string

// ToViperKey converts an entry ID to its viper key.
// Nested: "db" object, "host" property → "db.host"
func ToViperKey(parentPath, id string) string
```

## Template guidelines

- Use `text/template` (not `html/template`)
- Define template helper functions: `goName`, `structName`, `viperKey`, `isObject`, `isSensitive`, `isComputed`, `isLive`, `hasScope`
- Template must produce syntactically valid Go; test by passing output to `go/format.Source()`
- Use `{{- }}` and `{{ -}}` for whitespace control to avoid blank lines in output
- Template file is in `gen/codegen/templates/config.go.tmpl`; embed with `//go:embed templates/`

- All golden tests pass
- Generated code passes `go/format.Source()` without error
- Generated code for `testdata/schemas/full.go` compiles (`go build ./testdata/golden/...`)
- `go vet ./gen/codegen/...` clean
- No use of `fmt.Sprintf` to build Go source strings (use template only)
