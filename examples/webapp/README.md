# webapp — cfgx example project

A realistic cobra/viper application demonstrating the full cfgx workflow.

## Commands

- `webapp serve` — start the HTTP server
- `webapp migrate` — run database migrations

## Key design points

- `cmd/schema.go` declares all configurations using `cfgx.Define()`
- `cmd/config.gen.go` is generated by `cfgx gen` — do not edit manually
- `pkg/server/` and `pkg/database/` define their own `Config` interfaces
  and **import zero cfgx or viper code** — they are satisfied via Go's structural typing

## Getting started

1. Install cfgx:
   ```sh
   go install github.com/example/cfgx/cmd/cfgx@latest
   ```

2. Generate configuration code:
   ```sh
   go generate ./cmd/...
   ```

3. Build:
   ```sh
   go build ./...
   ```

4. Run:
   ```sh
   # Copy the example env file and fill in required values
   cp .env.example .env
   # Edit .env: set DB_NAME and DB_PASSWORD at minimum

   # Source the env and run
   source .env
   ./webapp serve
   ```
